# Sonic Agent downloads

This repository only hosts the Sonic Agent installers. The app's source code is private.

**Mac:** [Sonic-Agent-arm64.dmg](https://github.com/lebtiga/sonic-agent-releases/releases/latest/download/Sonic-Agent-arm64.dmg)

**Windows (beta):** [Sonic-Agent-Setup.exe](https://github.com/lebtiga/sonic-agent-releases/releases/latest/download/Sonic-Agent-Setup.exe)

Sonic Agent is for Sonic members. You sign in with your Sonic license after you install it. Not a member yet? See [sonic777.ai](https://sonic777.ai).

Requirements:

- Mac: Apple silicon (M1 or newer), macOS 13 or newer.
- Windows: Windows 10 or 11, 64-bit Intel or AMD PC.
- Both: a Claude subscription for Claude Code. The app walks you through installing Claude Code the first time you open it.

On Windows, the first time you open the installer Windows may say "Windows protected your PC". Click More info, then Run anyway.
