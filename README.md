# Sonic Agent downloads

This repository only hosts the Sonic Agent installer for Mac. The app's source code is private.

**Download:** [Sonic-Agent-arm64.dmg](https://github.com/lebtiga/sonic-agent-releases/releases/latest/download/Sonic-Agent-arm64.dmg)

Sonic Agent is for Sonic members. You sign in with your Sonic license after you install it. Not a member yet? See [sonic777.ai](https://sonic777.ai).

Requirements: a Mac with Apple silicon (M1 or newer), macOS 13 or newer, and a Claude subscription for Claude Code. The app walks you through installing Claude Code the first time you open it.
